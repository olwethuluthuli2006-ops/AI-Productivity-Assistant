# Mercedes Drive Companion

Build a modern, responsive web application called “My Mercedes Drive”.

My Mercedes Drive is an independent digital car diary and vehicle companion
application designed for Mercedes-Benz owners. It helps users manage vehicle
information, important dates, driving memories, documents, reminders,
roadside assistance, emergency services, and vehicle-related help from one
simple dashboard.

The application must have exactly four main navigation tabs:

1. Home
2. My Diary
3. Help
4. Settings

The application should feel premium, elegant, trustworthy, and automotive
focused. Use a modern SaaS dashboard layout with responsive desktop, tablet,
and mobile designs.

Important branding requirement:
Do not use official Mercedes-Benz logos, copyrighted images, or official
Mercedes-Benz brand assets. Use a tasteful premium automotive design inspired
by black, white, silver, charcoal, and subtle red or blue accents. Include
this disclaimer in the footer or Settings page:

“My Mercedes Drive is an independent application and is not affiliated with,
endorsed by or sponsored by Mercedes-Benz AG.”

==================================================
GENERAL DESIGN REQUIREMENTS
==================================================

Create a polished interface with:

- Responsive desktop and mobile layouts
- Bottom navigation or collapsible sidebar on mobile
- Sidebar navigation on desktop
- Premium automotive visual style
- Clean white, charcoal, black, silver, and dark-gray colors
- Optional red or blue accent color
- Rounded cards with subtle shadows
- Clear typography and accessible contrast
- Modern icons using Lucide or another consistent icon library
- Smooth but subtle animations
